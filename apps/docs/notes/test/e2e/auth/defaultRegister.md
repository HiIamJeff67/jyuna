### Procedures:
* User can NOT register with an invalid user name input
	* Valid Form : 
		* length of 6 ~ 20 characters
		* containing only english and numbers

* User can NOT register with an invalid display name input
	* Valid Form : 
		* length of 3 ~ 30 characters
		* containing only english and numbers

* User can NOT register with an invalid email input
	* Valid Form : 
		* containing `@` sign, and `.` sign between two separated strings behind `@`

* User can NOT register with an invalid password input
	* Valid Form : 
		* length of 8 ~ characters
		* containing at least one lower case english letters, a upper case english letters, a number, and a sign

* User can register with some given valid user name, display name, email, and password inputs
